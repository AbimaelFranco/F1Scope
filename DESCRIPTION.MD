**F1Scope** es una aplicación interactiva para visualizar y analizar carreras de Fórmula 1 a partir de datos históricos obtenidos mediante la API de OpenF1.

El proyecto busca reconstruir cada carrera de manera visual, representando el circuito en un entorno 3D y reproduciendo el desplazamiento de los monoplazas a lo largo del tiempo según sus posiciones y datos registrados durante la carrera. El usuario podrá controlar la reproducción y observar cómo evoluciona la carrera, incluyendo posiciones, vueltas y diferencias entre pilotos.

Además del replay 3D, F1Scope incorporará herramientas de análisis de telemetría que permitirán seleccionar pilotos y comparar diferentes variables, como velocidad, aceleración y comportamiento a lo largo de una vuelta o durante una carrera. Los datos se mostrarán mediante gráficos interactivos sincronizados con la reproducción, permitiendo analizar momentos específicos y comparar el rendimiento de distintos pilotos.

La interfaz tendrá una estética **cyberpunk/tecnológica**, utilizando visualizaciones 3D, elementos tipo HUD y colores neón para crear la sensación de una estación de análisis de datos de competición.

En conjunto, el proyecto combina **desarrollo de software, visualización 3D, procesamiento de datos, análisis de telemetría y motorsport**, utilizando datos reales de Fórmula 1 para explorar de forma interactiva cómo se desarrolla una carrera.
